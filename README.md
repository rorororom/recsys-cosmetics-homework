# Домашнее задание 1: рекомендательные системы

**Ромашкина Мария Михайловна**

Датасет: [eCommerce Events History in Cosmetics Shop](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop), REES46, октябрь 2019. [Первоисточник](https://data.rees46.com/).

Работа находится в `experiments.ipynb`. Пять моделей реализованы в `models/`. Подготовка данных и оценка качества находятся в ноутбуке.

## Запуск

```bash
pip install "jupyterlab>=4,<5"
jupyter lab experiments.ipynb
```

Зависимости для экспериментов устанавливаются первой кодовой ячейкой ноутбука.
